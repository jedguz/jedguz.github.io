# Jed Guzelkabaagac

Personal academic website at https://jedguz.github.io/.

A single static HTML page with a stylesheet and photograph. Open index.html directly or serve this directory with any static HTTP server. No dependencies or build step are required.

The .nojekyll file makes this directory suitable for a branch-based GitHub Pages deployment. Confirm the repository Pages source before deploying.

Edit index.html for biography, contact details, and publications; edit assets/style.css for layout. The full-aspect-ratio portrait is in assets/portrait-oxford.jpeg.

The previous AcademicPages site remains in Git history.
